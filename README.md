# Chess Website

A real-time multiplayer chess game built using **Node.js, Express.js, Socket.IO, Chess.js, and EJS**. Players can create or join rooms to play with friends directly.

## 🚀 Features

- 🏆 **Real-time Gameplay:** Uses **Socket.IO** for smooth and interactive gameplay.
- 🎭 **Room-Based Matchmaking:** Players can enter a room name and invite a friend.
- 📜 **Chess Logic:** Powered by **Chess.js** for game rules and legal move validation.
- 🎨 **User Interface:** Built with **EJS, HTML, CSS, and JavaScript**.
- 🛠 **Express.js Backend:** Manages connections and game states.
- 🔄 **Move Validation & Turn Management:** Ensures fair play with turn-based logic.

## 🛠 Technologies Used

- **Node.js** – Backend runtime
- **Express.js** – Web framework
- **Socket.IO** – Real-time communication
- **Chess.js** – Chess rules and move validation
- **EJS** – Template engine for dynamic UI rendering
- **HTML, CSS, JavaScript** – Frontend UI

## 📦 Installation & Setup

### Clone the Repository
```bash
git clone https://github.com/Aakash17x08/Chess.git
cd chess-project
```

### Install Dependencies
```bash
npm install
```

### Start the Server
```bash
node app.js
```

### Open the Game in the Browser
```
http://localhost:3000
```
